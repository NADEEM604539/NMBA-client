# Azure Communication Services Email Setup

This project sends **real order confirmation emails** to customer inboxes using **Azure Communication Services**.

## 🚀 How to Get Azure API Keys (Step-by-Step)

### Step 1: Create Azure Account

1. Go to [https://azure.microsoft.com](https://azure.microsoft.com)
2. Click **Start free** 
3. Sign in with Microsoft account (Gmail, Outlook works too)
4. Verify phone and add credit card (FREE tier, won't charge)
5. Click **Go to Azure Portal** after setup

### Step 2: Create Communication Services Resource

1. In **Azure Portal**, click top-left **Menu** (☰)
2. Search for **"Communication Services"**
3. Click **Communication Services** from results
4. Click **+ Create** button

**Fill in these details:**
- **Resource Group**: Click **Create new** → Type `email-service`
- **Resource Name**: Type `afiasherbal` (or any name)
- **Data Location**: Choose `United States` (or your region)
- **Click Review + create**
- **Click Create** (wait 2-3 minutes)

### Step 3: Copy Connection String

1. After creation, click **Go to resource**
2. Left sidebar → Click **Keys**
3. Copy the **Primary connection string** (the long one):

```
endpoint=https://afiasherbal.communication.azure.com/;accesskey=xxxxxxxxxxx
```

### Step 4: Create Email Domain

1. Still in your resource, left sidebar → Click **Emails**
2. Click **Provision Domains** button
3. Select **Azure managed domain** (free option)
4. Click **Add** → Type domain name → **Create**
   - Example: `afiasherbal` → `AutoGenerated.azure@afiasherbal.azurecomm.net`

Wait 5-10 minutes for domain to activate.

Your **sender email** will be:
```
DoNotReply@afiasherbal.azurecomm.net
```

### Step 5: Add to .env File

Open `.env` and replace with your actual values:

```env
AZURE_COMMUNICATION_CONNECTION_STRING=endpoint=https://afiasherbal.communication.azure.com/;accesskey=xxxxxxxxxxx
AZURE_SENDER_EMAIL=DoNotReply@afiasherbal.azurecomm.net
```

## 🆘 Troubleshooting

### Emails not sending?

**Check 1: Is `.env` updated?**
```
AZURE_COMMUNICATION_CONNECTION_STRING=endpoint=...
AZURE_SENDER_EMAIL=DoNotReply@...
```

**Check 2: Did you restart dev server?**
```bash
npm run dev
```

**Check 3: Is email domain activated?**
- Go to Azure Portal > Communication Services > Emails
- Check domain status (should be "Active")

**Check 4: Check server logs**
- Look for error messages in terminal
- Common: "Azure not configured"

### Error: "Azure not configured"
- Missing `.env` variables
- Check both variables are present
- Restart server

### Error: "Unauthorized"
- Connection string is wrong
- Copy exact value from Azure Portal > Keys

### Domain not activating?
- Wait 5-10 minutes
- Refresh Azure Portal
- Check status under Emails > Domains
